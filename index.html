Le principe

Tu notes le SFS, Infloww remplit les résultats

1. ＋ Nouveau SFS : modèle, partenaire, contact, date+heure.
2. Le site te donne le nom exact à mettre sur ton lien Infloww — nomme-le pareil.
3. Une fois envoyé, clique le statut → Envoyé.
4. Titouan importe l'export Infloww → les stats et la note /10 se collent, statut → Mesuré.
Clique le nom d'un partenaire (en bleu) pour voir sa fiche complète.
